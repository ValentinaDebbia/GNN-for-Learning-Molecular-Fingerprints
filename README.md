# GNN-for-Learning-Molecular-Fingerprints
This repository contains a modern review and analysis of the foundational paper "Convolutional Networks on Graphs for Learning Molecular Fingerprints" (Duvenaud et al., 2015), along with the original authors' codebase. Developed for the Machine Learning on Graphs course (A.Y. 2025/2026, University of Milan).

# Overview

Molecular fingerprinting is a crucial task in cheminformatics, as the accurate representation of chemical structures is essential for drug discovery and property prediction.
However, traditional hand-crafted fingerprints (such as ECFP) rely on fixed, predefined substructure rules, limiting their flexibility and adaptability across different tasks. This project presents a modern review and analysis of the foundational paper "Convolutional Networks on Graphs for Learning Molecular Fingerprints" (Duvenaud et al., 2015), which introduced a data-driven approach to learn differentiable, end-to-end molecular representations directly from graph structures.
